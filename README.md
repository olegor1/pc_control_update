## О проекте

**PC Control Bot** — десктопное приложение для Windows на **Rust + Tauri 2**. Оно живёт в системном трее и позволяет управлять компьютером двумя способами:

- через **Telegram-бота**;
- через мобильное приложение **PC Control** для Android.

Белый IP и проброс портов не нужны: ПК сам подключается к relay-серверу по защищённому WebSocket (`wss://`), а команды между телефоном и ПК шифруются сквозным шифрованием.

### Ключевые возможности

- **Таймер выключения** — быстрые пресеты (5, 15, 30 минут, 1 и 2 часа) и своё время, обратный отсчёт и отмена
- **Telegram-бот** — кнопки и команды, обратный отсчёт обновляется прямо в сообщении
- **Подключение телефона** — 6-значный код или QR в окне приложения, отзыв любого телефона в один клик
- **Мониторинг системы** — ОС, аптайм, CPU, память, диск
- **Авторизация** — бот отвечает только пользователям из белого списка Telegram ID
- **Трей и автозапуск** — работает тихо в фоне, меню с быстрыми таймерами в трее
- **Автообновление** — проверка релизов на GitHub раз в 6 часов
- **Интерфейс** — светлая, тёмная и автоматическая темы, языки: русский, украинский, английский

## Установка

### Требования

- Windows 10 / 11
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (в Windows 11 уже установлен)
- Подключение к интернету

### Шаги

1. Скачайте последний установщик `.exe` из раздела [Releases](https://github.com/olegor1/pc_control_update/releases)
2. Запустите его — установка идёт в профиль текущего пользователя, права администратора не нужны
3. Подключите телефон и/или настройте Telegram-бота (см. ниже)

> Приложение распространяется только в виде установщика. Portable-версии нет.

---

## Подключение мобильного приложения

1. Откройте PC Control Bot на компьютере, раздел **«Мобильное приложение»**
2. Нажмите **«Подключить телефон»** — появится 6-значный код и QR
3. В Android-приложении выберите **«Добавить устройство»** и введите код или отсканируйте QR
4. Телефон появится в списке подключённых. Отозвать его можно в любой момент как на ПК, так и на самом телефоне

При сопряжении телефон и ПК обмениваются эфемерными ключами X25519 через сервер. Сервер общий секрет вычислить не может, поэтому читать команды он не способен.

## Настройка Telegram-бота

### 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте полученный **API Token**

### 2. Узнайте свой Telegram ID

Откройте [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш числовой ID. Узнать его также можно у самого бота кнопкой **«🆔 Мой ID»**.

### 3. Введите данные в приложение

В разделе **Настройки** PC Control Bot:
- вставьте токен бота;
- добавьте свой Telegram ID в список авторизованных;
- запустите бота и отправьте ему `/start`.

## Команды бота

| Команда / кнопка | Описание |
|------------------|----------|
| `/start` | Главное меню с кнопками управления |
| `🔴 Выключить ПК` | Меню выключения: сразу (с подтверждением) или по таймеру |
| `⏱ Быстрый таймер` | Пресеты 5, 10, 15, 30 минут, 1 и 2 часа и ввод своего времени |
| `❌ Отменить таймер` | Отмена запланированного выключения |
| `💻 Информация` | ОС, аптайм, CPU, память, диск |
| `🆔 Мой ID` | Ваш Telegram ID для списка доступа |
| `🔄 Перезапустить бота` | Сброс состояния диалога |

Свой таймер задаётся числом минут от 1 до 1440 (24 часа). Если таймер запущен с самого ПК, бот присылает уведомление с обратным отсчётом, который обновляется каждые 10 секунд.

## Команды с телефона

Relay-протокол принимает от сопряжённого телефона только строго ограниченный набор действий:

| Действие | Описание |
|----------|----------|
| `shutdown` | Выключение сразу или с задержкой |
| `restart` | Перезагрузка |
| `sleep` | Переход в спящий режим |
| `cancel` | Отмена запланированного выключения |
| `get-status` | Запрос статуса системы |

Любая другая команда отклоняется.

## Конфигурация

Настройки лежат в `%APPDATA%\PC Control Bot\config.json` и сохраняются между сессиями:

```json
{
  "telegramToken": "dpapi:v1:...",
  "authorizedUsers": ["123456789"],
  "startMinimized": false,
  "autoStart": false,
  "theme": "auto",
  "language": "ru"
}
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `telegramToken` | `string` | Токен бота от @BotFather |
| `authorizedUsers` | `string[]` | Белый список Telegram ID |
| `startMinimized` | `boolean` | Запуск сразу в трей |
| `autoStart` | `boolean` | Автозапуск при старте Windows |
| `theme` | `string` | `"light"` / `"dark"` / `"auto"` |
| `language` | `string` | `"ru"` / `"uk"` / `"en"` |

Также в файле хранятся служебные данные сопряжения: токен комнаты relay, список телефонов и их ключи шифрования. Файл пишется атомарно (временный файл + переименование), поэтому оборванная запись не повредит настройки.

Логи пишутся в `%LOCALAPPDATA%\com.pccontrol.bot\logs\pc-control-bot.log`. Если телефон не подключается, начните с них.

## Безопасность

- **Сквозное шифрование (E2E)** — X25519 + HKDF-SHA256 + AES-256-GCM. Relay-сервер передаёт только зашифрованные сообщения. Совместимость с Android закреплена тестами с «золотыми векторами»: шифртекст должен совпадать побайтово
- **Certificate pinning** — собственный `ServerCertVerifier` на rustls принимает ровно один вшитый сертификат сервера (`src-tauri/assets/relay-cert.pem`), а не любой, подписанный системными CA
- **Шифрование секретов через Windows DPAPI** — токен Telegram, токен комнаты и ключи телефонов хранятся с префиксом `dpapi:v1:`. Украденный файл бесполезен на другой машине или под другим пользователем. Это защита от утечки файла, но не от вредоносной программы, запущенной под тем же пользователем
- **Белый список Telegram ID** — остальным бот отвечает отказом
- **Минимальные права окна** — интерфейс обращается к системе только через собственные команды Tauri (`capabilities/default.json`), а CSP запрещает внешние ресурсы
- **Валидация задержки** — значение проверяется на допустимый диапазон до запуска `shutdown`
